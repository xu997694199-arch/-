# String Desk — interactive project demo

String Desk is a self-initiated localization-review prototype. It is a working application interface, not a portfolio website or a client deployment. The interface is primarily Simplified Chinese, with English source strings and section labels.

## Open the project

[Download the single-file HTML](https://raw.githubusercontent.com/xu997694199-arch/-/main/demos/string-desk/index.html), save it as `string-desk.html`, and open it in a desktop browser. GitHub may display the source first; use **Download raw file**. This link is a downloadable demo, not a hosted deployment. No installation, account, API key, or network connection is needed after downloading.

The initial screen contains 30 fictional gardening-game strings, with deliberately seeded validation issues. These are demonstration fixtures, not customer findings.

## Quick walkthrough

- Select a string in the left list to inspect its source, context, and editable translation.
- **保存改动并检查** saves the current edit and runs the available checks.
- **有问题** filters the list to flagged strings.
- **载入修正样例** loads the corrected fictional dataset.
- CSV/JSON import and exports run within the browser. Refreshing or closing can discard edits; export first.

The checks cover simple placeholders and common paired tags. They do not certify translation meaning, complex ICU messages, or actual game rendering.
